# ระบบงานเบิกของและ Skill Matrix

**เว็บใช้งาน:** https://nk02388-cyber.github.io/Withdrawal-Skill-Matrix/

**GitHub:** https://github.com/nk02388-cyber/Withdrawal-Skill-Matrix

เปิดเว็บแล้วดู Dashboard, ใบเบิก และ Skill Matrix ได้ทันทีโดยไม่ต้อง Login ข้อมูลอยู่ใน Supabase กลางและโหลดใหม่ทุก 15 วินาทีเมื่อหน้าเว็บเปิดอยู่ จึงใช้งานหลายเครื่องได้

## เพิ่มและแก้ข้อมูล

กด **ใส่รหัสแก้ข้อมูล** ที่มุมขวาบนแล้วกรอกรหัสร่วม รหัสใช้กับการเพิ่มพนักงาน, เพิ่ม Job, กำหนดระดับทักษะ, สร้างใบเบิก และกดเริ่ม/จบงาน กด **ปิดโหมดแก้ไข** เมื่อต้องการกลับไปดูข้อมูลอย่างเดียว รหัสคงอยู่ในแท็บนั้นจนกว่าจะปิดแท็บหรือปิดโหมดแก้ไข

1. เพิ่มพนักงานในหน้า **พนักงาน**
2. เพิ่ม Job ในหน้า **ประเภทงานและทักษะ** แล้วกำหนดระดับ 0–4
3. สร้างใบเบิก ระบุเลขที่ใบเบิก, Job, ผู้รับผิดชอบ และรายละเอียด
4. กด **เริ่มงาน** และ **จบงาน** เวลามาจากฐานข้อมูลกลาง

ระดับทักษะเป็นการประเมินที่ใส่เอง ตัวเลข “งาน” ใน Skill Matrix คือจำนวนใบเบิกที่จบแล้ว ค่า 0 หมายถึงยังไม่ประเมิน

## ขอบเขตการเข้าถึง

ทุกคนที่มีลิงก์ดูข้อมูลทั้งหมดได้ ผู้ที่รู้รหัสร่วมแก้ข้อมูลได้ทุกส่วน ระบบนี้ไม่มีการระบุตัวบุคคลที่กดแก้หรือกดเวลา จึงไม่เหมาะใช้เป็นหลักฐานเวลาทำงานที่ต้องตรวจสอบผู้กระทำเป็นรายคน อย่าใส่ข้อมูลลับหรือข้อมูลส่วนบุคคลที่ไม่ต้องการให้คนที่มีลิงก์เห็นในใบเบิก

รหัสร่วมถูกเก็บเป็น hash ใน Supabase และไม่ได้อยู่ใน GitHub `config.js` มีเฉพาะ publishable key ที่เปิดเผยได้ ปุ่มแก้ไขเรียกฟังก์ชันฐานข้อมูลซึ่งตรวจรหัสทุกครั้ง การอ่านใช้ฟังก์ชันที่คืนเฉพาะข้อมูลสำหรับ Dashboard โดยไม่เปิดตารางบัญชีเดิมหรืออีเมล

## สำหรับดูแลระบบ

- `schema.sql` เป็นโครงสร้างเดิมของโครงการ
- `no-login-migration.sql` เพิ่มโหมดดูข้อมูลสาธารณะและรหัสร่วม รันต่อจาก `schema.sql` ในโครงการใหม่
- หลังรัน migration ต้องตั้งค่า `app_settings.edit_code` เป็น hash ของรหัสร่วมก่อนเปิดให้แก้ข้อมูล
- `app.js` ใช้ Supabase RPC ไม่มีรหัสร่วมฝังในไฟล์
- ไฟล์เว็บถูกโฮสต์จาก root ของ branch `main` บน GitHub Pages
