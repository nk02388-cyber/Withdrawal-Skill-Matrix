# ระบบงานเบิกของและ Skill Matrix

เว็บแอปสำหรับมอบหมายใบเบิกให้พนักงาน บันทึกเวลาเริ่มและจบงาน และดู Skill Matrix รายคน ข้อมูลอยู่ใน Supabase โครงการ `Withdrawal Skill Matrix` จึงเปิดจากหลายเครื่องแล้วเห็นข้อมูลชุดเดียวกัน หน้าเว็บโฮสต์บน GitHub Pages

## การใช้งาน

1. สมัครบัญชีด้วยอีเมลและยืนยันอีเมลตามข้อความจาก Supabase
2. ผู้ดูแลเปิดสิทธิ์บัญชีพนักงานในหน้า **พนักงาน**
3. ผู้ดูแลเพิ่ม Job ในหน้า **ประเภทงานและทักษะ** แล้วกำหนดระดับทักษะ 0–4
4. ผู้ดูแลสร้างใบเบิก ระบุเลขที่ใบเบิก, Job, พนักงานรับผิดชอบ และรายละเอียด
5. พนักงานกด **เริ่มงาน** และ **จบงาน** เวลาประทับโดยฐานข้อมูลกลาง

ระดับทักษะเป็นการประเมินโดยผู้ดูแล ส่วนตัวเลข “งาน” ใน Skill Matrix คือจำนวนใบเบิกที่จบแล้วของพนักงานและ Job นั้น ค่า 0 หมายถึงยังไม่ประเมิน ไม่ได้หมายถึงไม่มีความสามารถ

## เปิดสิทธิ์ผู้ดูแลคนแรก

เมื่อบัญชี `nk02388@gmail.com` สมัครและยืนยันอีเมลแล้ว ให้รันคำสั่งนี้ใน Supabase SQL Editor หนึ่งครั้ง:

```sql
update public.profiles
set role = 'admin', active = true
where email = 'nk02388@gmail.com'
  and id in (select id from auth.users where email_confirmed_at is not null);
```

ผลลัพธ์ต้องเป็น **1 row** จากนั้นออกจากระบบและเข้าสู่ระบบใหม่ หากยังเป็น 0 rows ให้ตรวจว่าได้สมัครและยืนยันอีเมลแล้ว

## โครงสร้างและความปลอดภัย

- `index.html`, `styles.css`, `app.js` เป็นเว็บสแตติก ไม่มีเซิร์ฟเวอร์ที่ GitHub
- `config.js` เก็บ URL และ **publishable key** ซึ่งออกแบบให้เปิดเผยในเบราว์เซอร์ได้ ห้ามใส่ service role key
- `schema.sql` เป็น migration ของตาราง, Row Level Security และฟังก์ชันเริ่ม/จบงาน
- บัญชีใหม่ถูกปิดสิทธิ์โดยเริ่มต้น ผู้ดูแลเห็นทุกงาน พนักงานเห็นเฉพาะงานและทักษะของตน
- เวลาเริ่ม/จบมาจาก `clock_timestamp()` ของฐานข้อมูล ป้องกันเครื่องผู้ใช้ตั้งเวลาผิด
- หน้าเว็บโหลดข้อมูลใหม่ทุก 15 วินาทีขณะเปิดอยู่ และมีปุ่มรีเฟรช

## การพัฒนาในเครื่อง

เสิร์ฟโฟลเดอร์นี้ผ่าน HTTP เช่น `npx serve .` แล้วเปิด URL ที่ได้ ไม่ควรเปิด `index.html` ด้วย `file://` เพราะเป็น JavaScript module

## การนำไปใช้กับโครงการ Supabase อื่น

สร้างโครงการใหม่ รัน `schema.sql` ใน SQL Editor แล้วใส่ Project URL และ publishable key ใน `config.js` ก่อนเผยแพร่เว็บ
